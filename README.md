# Portofolio-El-Jalaluddin-Rumi
Siswa Teknik Komputer dan Jaringan (TKJ) International Class Program di SMK Telkom Malang dengan minat kuat pada bidang Cyber Security. Berdedikasi tinggi, terbiasa bekerja sama dalam tim, serta aktif mengembangkan keterampilan teknis dalam arsitektur jaringan dan keamanan siber untuk masa depan.
